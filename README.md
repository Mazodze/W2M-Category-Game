# Letter Rush — Multiplayer Prototype

## Run locally

1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run:

   npm install
   npm start

4. Open http://localhost:3000 in your browser.
5. Open the same address in 3+ browser tabs/windows to simulate players.
6. One player hosts and shares the 5-digit room code.

## Current prototype

- 2–8 players per room (4+ supported)
- Host creates a 5-digit code
- Players join the same lobby
- Host starts the game
- Animated alphabet spin
- Random letter
- Categories: Cars, Country, Food, Animal, Name
- First player to press STOP ends the round
- Results display
- Next round

## Important

This is a prototype, not a production-ready game. Answer validation/scoring, reconnection, anti-cheat, matchmaking, persistent accounts, and deployment are intentionally simplified for the first version.
